# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is an open-source Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The duration in years.

## Example
If the principal is 1000, the annual interest rate is 5%, and the time period is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100

## How to Run
1. Open a Bash terminal.
2. Navigate to the directory containing `simple-interest.sh`.
3. Run the command:

```bash
bash simple-interest.sh
```

4. Enter the principal amount, interest rate, and time period when prompted.
